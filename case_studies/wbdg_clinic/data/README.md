# WBDG Medical Clinic --- Dataset Setup

## Source

**URL:** https://www.wbdg.org/bim/cobie/common-bim-files

Dataset: "Medical Clinic" --- US General Services Administration sample project.
License: Public Domain (US Federal Government work).

## Files Available

The WBDG Medical Clinic provides IFC 2x3 models across **5 disciplines**
(ARC, STR, MEP, ELE, PLB), making it the most complete WBDG dataset for
coordination testing. Two variants exist for some models: original and
Solibri-optimized. The script auto-selects the optimized variant.

## Download Steps

1. Go to https://www.wbdg.org/bim/cobie/common-bim-files
2. Under "Medical Clinic", download these 4 ZIPs:
   - **Coordination Model View** section: `2011-09-14-Clinic-IFC.zip`
   - **HVAC System (HVACie)** section: `Clinic_M_20120330_IFC_optimized.zip`
   - **Electrical System (Sparkie)** section: `Clinic_Electrical_20121207.zip`
   - **Water System (WSie)** section: `Clinic_Plumbing_IFC_20121206.zip`
3. Extract all ZIPs and place the `.ifc` files in this `ifc/` directory
4. No renaming needed --- the script detects discipline from filenames
5. Delete the ZIP files from `ifc/` (optional, they are ignored)

## Running the Pipeline

```bash
cd case_studies

# Step 1: Generate clashes from IFC models
python scripts/generate_clashes.py --project wbdg_clinic --rounds 6

# Step 2: Generate supplementary data (RFIs, submittals, meetings)
python scripts/prepare_data.py --project wbdg_clinic

# Step 3: Run full analysis (all 5 metrics + ECV + benchmarks)
python scripts/run_analysis.py --project wbdg_clinic

# Step 4: Generate publication figures
python scripts/generate_visuals.py --project wbdg_clinic --format png --dpi 300
```

## Without IFC Files

The pipeline works without IFC files. `generate_clashes.py` falls back to
synthetic clash generation:

```bash
python scripts/generate_clashes.py --project wbdg_clinic
```
