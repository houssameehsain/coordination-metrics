# WBDG Duplex Apartment --- Dataset Setup

## Source

**URL:** https://www.wbdg.org/bim/cobie/common-bim-files

Dataset: "Duplex Apartment" --- US General Services Administration sample project.
License: Public Domain (US Federal Government work).

## Files Available

The WBDG Duplex dataset provides IFC 2x3 models across 4 disciplines,
exported from Autodesk Revit. Two variants exist for the 2011 models:
original and Solibri-optimized (same geometry, smaller file). The script
auto-selects the optimized variant when both are present.

### Clash test pairs

With 4 disciplines the script runs up to 7 cross-discipline clash tests:

| Test | Discipline A | Discipline B |
|---|---|---|
| MEP-Structure | MEP | STR |
| Electrical-Structure | ELE | STR |
| Plumbing-Structure | PLB | STR |
| MEP-Architecture | MEP | ARC |
| Electrical-Mechanical | ELE | MEP |
| Plumbing-Mechanical | PLB | MEP |
| Electrical-Plumbing | ELE | PLB |

Note: STR tests will be skipped (no structural model in this dataset),
leaving 4 active test pairs: MEP-ARC, ELE-MEP, PLB-MEP, ELE-PLB.

## Download Steps

1. Go to https://www.wbdg.org/bim/cobie/common-bim-files
2. Under "Duplex Apartment", download these 3 ZIPs:
   - **Coordination Model View** section: `2011-09-14-Duplex-IFC.zip`
   - **Electrical System (Sparkie)** section: `Duplex_Electrical_20121207.zip`
   - **Water System (WSie)** section: `Duplex_Plumbing_IFC_20121113.zip`
3. Extract all ZIPs and place the `.ifc` files in this `ifc/` directory
4. No renaming needed --- the script detects discipline from filenames
5. Delete the ZIP files from `ifc/` (optional, they are ignored by the script)

## Running the Pipeline

```bash
cd case_studies

# Step 1: Generate clashes from IFC models (or synthetic fallback)
python scripts/generate_clashes.py --project wbdg_duplex --rounds 5

# Step 2: Generate supplementary data (RFIs, submittals, meetings)
python scripts/prepare_data.py --project wbdg_duplex

# Step 3: Run full analysis (all 5 metrics + ECV + benchmarks)
python scripts/run_analysis.py --project wbdg_duplex

# Step 4: Generate publication figures
python scripts/generate_visuals.py --project wbdg_duplex --format pdf --dpi 300
```

## Without IFC Files

The pipeline works without IFC files. `generate_clashes.py` falls back to
synthetic clash generation with realistic project distributions:

```bash
python scripts/generate_clashes.py --project wbdg_duplex
# Generates synthetic data for pipeline testing
```
